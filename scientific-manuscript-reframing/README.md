# Scientific Manuscript Reframing

A general-purpose skill for diagnosing and restructuring scientific manuscripts.

## What it does

It helps move a manuscript from a collection of analyses to a coherent scientific argument by working through:

> Evidence → Question → Central claim → Argument structure → Section architecture → Claim calibration → Journal positioning

## What it does not assume

The skill does **not** assume any particular discipline, study design, data type, model family, classification system, analytical structure, or application domain.

Any such structure should be introduced only when supported by the manuscript being analyzed.

## Modes

- `DIAGNOSE` — identify scientific and structural problems before rewriting.
- `REFRAME` — rebuild the central argument and manuscript architecture.
- `SECTION` — revise a specific manuscript section.
- `SYNTHESIZE` — integrate multiple analyses into a higher-level relationship or framework.
- `SUBMISSION` — adapt a stable manuscript to a target journal and prepare submission materials.

## Recommended use

For a structurally weak draft, start with `DIAGNOSE`, then use `REFRAME`, then revise sections. Do not begin with sentence-level polishing unless the scientific argument is already stable.
