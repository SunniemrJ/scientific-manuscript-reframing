# Output Templates

Use these as structures, not rigid forms.

## DIAGNOSE output

### 1. One-sentence diagnosis
What is the manuscript's main structural or scientific problem?

### 2. Current argument
3–5 sentences summarizing what the manuscript currently claims.

### 3. Evidence-backed argument
3–5 sentences summarizing what the evidence most convincingly supports.

### 4. Strongest contribution
One sentence.

### 5. Main problems
Ranked by importance:
- scientific logic;
- missing relationship;
- weak evidence;
- repetition;
- overclaim;
- unclear novelty;
- section mismatch.

### 6. Reviewer risks
Top 3–5.

### 7. Reframing option
Proposed central question, take-home statement, and section sequence.

## REFRAME output

### Scientific question
One sentence.

### Take-home message
One sentence.

### Argument map
Use arrows only when the relationship is actually supported, e.g.:

> Evidence block A → key relationship → evidence block B → synthesis → implication

### Revised section architecture
For each section:
- purpose;
- key evidence;
- takeaway;
- transition.

### Missing work
Separate essential from optional.

## SECTION output

### Section job
What should this section accomplish?

### Current problem
Why does it not yet accomplish that job?

### Proposed logic
Paragraph-by-paragraph or subsection-by-subsection sequence.

### Revised text
Only after the logical structure is clear or when the user explicitly requests direct rewriting.

## SYNTHESIZE output

### Evidence being integrated
List the relevant analyses.

### Candidate relationship/framework
State the synthesis.

### What it explains
Be precise.

### What it does not explain
State boundaries.

### Validation needed
If applicable.

### Recommended presentation
Table, figure, conceptual diagram, grouping, matrix, or prose.

## SUBMISSION output

### Journal fit
- strong points;
- risks;
- framing changes.

### Submission assets
As requested:
- title;
- abstract;
- keywords;
- highlights;
- cover letter;
- graphical-abstract concept.
