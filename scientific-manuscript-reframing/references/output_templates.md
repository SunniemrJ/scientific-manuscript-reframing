# Output Templates

Use these as structures, not rigid forms. Apply the opening explanation and confirmation sequence in workflow.md first. For a new whole-manuscript task, first confirm the journal preference, then present the evidence inventory for confirmation before using the DIAGNOSE template. End each stage with a specific invitation to confirm or revise and identify the next stage.

## Literature basis for recommendations in every mode

For each substantive recommendation, identify the relevant manuscript evidence, the published finding or observed publication practice, and the reasoning for the proposed change. Give author, year, title and publication venue for cited papers and an original article or verified DOI link. State access limits if only the abstract was available. Literature_search.md specifies the stage-specific searches. End with the current decision for author confirmation.

## DIAGNOSE output

### 1. One-sentence diagnosis
What is the manuscript's main structural or scientific problem?

### 2. Current argument
3–5 sentences summarizing what the manuscript currently claims.

### 3. Evidence-backed argument
3–5 sentences summarizing what the evidence most convincingly supports.

### 4. Strongest contribution
One sentence.

### 5. Main problems
Ranked by importance:
- scientific logic;
- missing relationship;
- weak evidence;
- repetition;
- overclaim;
- unclear novelty;
- section mismatch.

### 6. Reviewer risks
Top 3–5.

### 7. Reframing option
Proposed central question, take-home statement, and section sequence.

## REFRAME output

### Scientific question
One sentence.

### Take-home message
One sentence.

### Argument map
Use arrows only when the relationship is actually supported, e.g.:

> Evidence block A → key relationship → evidence block B → synthesis → implication

### Revised section architecture
For each section:
- central message and its connection to the whole-paper claim;
- purpose;
- key evidence;
- takeaway;
- transition.

### Missing work
Separate essential from optional.

## SECTION output

### Section job
What should this section accomplish?

### Current problem
Why does it not yet accomplish that job?

### Proposed logic
Paragraph-by-paragraph or subsection-by-subsection sequence.

### Revised text
After the author confirms the section message and proposed logic, present the revised text for review. Ask whether it is accepted or needs adjustment before advancing.

## SYNTHESIZE output

### Evidence being integrated
List the relevant analyses.

### Candidate relationship/framework
State the synthesis.

### What it explains
Be precise.

### What it does not explain
State boundaries.

### Validation needed
If applicable.

### Recommended presentation
Table, figure, conceptual diagram, grouping, matrix, or prose.

## SUBMISSION output

### Journal fit
- strong points;
- risks;
- framing changes.

### Submission assets
As requested:
- title;
- abstract;
- keywords;
- highlights;
- cover letter;
- graphical-abstract concept.
