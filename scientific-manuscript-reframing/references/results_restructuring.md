# Results Restructuring

## Purpose

Organize Results by scientific questions and evidence progression rather than by the chronology of data processing.

## Core rule

Each subsection should answer one question.

A reader should be able to summarize each subsection as:

> The analysis showed that ______.

If the blank requires several unrelated claims, split or reorganize the subsection.

## Generic Results architectures

Choose only what fits the study.

### Architecture A — Descriptive to explanatory
1. data/sample/model quality;
2. primary pattern;
3. main contrast;
4. key relationship;
5. robustness or synthesis.

### Architecture B — Experimental
1. baseline/comparability checks;
2. primary treatment effect;
3. secondary outcomes;
4. interaction or mechanism tests;
5. robustness/sensitivity.

### Architecture C — Multi-method
1. result from method A;
2. result from method B;
3. agreement/disagreement;
4. integrated conclusion;
5. validation.

### Architecture D — Decision or application study
1. performance or baseline assessment;
2. comparison among alternatives;
3. trade-offs;
4. practical constraints;
5. decision-relevant synthesis.

## Subsection template

For each subsection:
1. **Opening answer** — state the main finding immediately.
2. **Evidence** — report the minimum quantitative detail needed.
3. **Contrast/relationship** — emphasize meaningful differences or associations.
4. **Boundary** — avoid mechanistic speculation unless directly tested.
5. **Transition** — explain why the next analysis is needed when useful.

## Keep Results concise

Do not:
- repeat every table value in prose;
- explain mechanisms not tested;
- repeat the same finding in multiple subsections;
- use `significant` without a statistical test;
- present exploratory analyses as confirmatory;
- interpret a model or index as direct real-world observation without qualification.

## Multiple outcomes or metrics

If several metrics represent different constructs, preserve that distinction.
Do not merge them simply for narrative convenience.

If a composite score or summary is used, state:
- what it contains;
- why aggregation is justified;
- what information is lost.

## Figures and tables

Use prose to explain the pattern, not to transcribe the figure.
A good Results paragraph should tell the reader what to notice and why it matters for the next question.
